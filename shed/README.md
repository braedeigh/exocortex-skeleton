# The shed

Things set down by `/shed` (`claude-commands/shed.md`) — code that was cold, moved here whole
instead of deleted. **Nothing in this directory is active in the app**: pytest, tsc, vite,
the router, and `server.py` none of them look here. Each folder has a `SHED.md` saying what it
was, why it was set down, and how to bring it back (`/shed restore <id>`).
