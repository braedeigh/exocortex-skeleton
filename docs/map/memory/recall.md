An agent starts each session knowing nothing about the owner's life. This part gives it the right memory at the right moment. The first time the owner names a person or a thread in a session, her recent cards about them are put into the agent's context.

Each load is written down. So the same cards are not loaded twice, and the owner can later judge whether a load was worth it.
