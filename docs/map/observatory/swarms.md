Sessions can message each other. A group of sessions that talked to each other is a swarm. Each swarm has a helper that names it, summarizes its members, and writes a closing summary when the swarm ends.

A Coding session that fills its context hands its work to a fresh session. The fresh session stays in the same swarm and line of work.
