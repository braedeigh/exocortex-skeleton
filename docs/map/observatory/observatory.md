The Observatory is the part of the app that runs agent sessions. Each session is a conversation with a Claude Code agent. The owner starts sessions, reads them, and answers them from one page.

Sessions work in rooms, talk to each other through a mailbox, and form swarms. Helper sessions watch the swarms and the rooms. Background parts start queued work, run long jobs, and fix notes at night.
