Linear is an outside issue tracker. The Linear room holds sessions that work in Linear, and it shows the Linear board on the page. Sessions reach Linear through its own tool server. The page reaches it through Linear's API with a personal key.

Once a minute the app asks Linear what other people did. A Linear helper is woken with the news and passes it on.
