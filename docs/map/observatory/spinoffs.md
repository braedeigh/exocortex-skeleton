A spinoff is a new session that a session or a button starts for a task. The new session starts working at once, without anyone opening it. A spinoff the owner starts with /spinoff plans first: a planning session that cannot edit agrees a plan with them, and their approval starts a second, fresh session that builds it. They can skip the plan from the Go card. It lands in the room of the session that started it and works in that room's folder.

Every spinoff remembers which session it came from. So the sessions can be drawn as a family tree.
